# ZERO ONE 8.1.0

## ZeroThink restored inside the desktop app

- Chat-first ZeroThink Studio with saved conversations, follow-up context, pinning, renaming, exports and an encrypted local source library.
- The original Zero mode's ALPHA/BETA/GAMMA/DELTA/EPSILON public work brief, Research → Critic → Final depth controls, user persona and explicitly remembered facts.
- Model replies enabled in Chat; useful model setup and transport errors instead of silently returning an offline checklist.
- Optional Serper snippets and an opt-in automatic web decision workflow. Queries go to Serper only when the user requests search or enables Auto web. Search snippets are labelled; they are not full page reads.
- A real native project agent: selected-folder file listing, reading and search; reviewed file writes; explicitly approved commands; captured tool results; bounded steps and Stop/Escape. A command runs with the user's OS permissions, so its working directory is not a sandbox.
- No hosted ZeroThink website, login, admin account or company database is required. The former browser integration is not used for ZeroThink.

## ZNotes repaired and expanded

- New note creates a saved note immediately. Edits autosave; switching sections retains and flushes the draft, with visible failures and retry.
- Quick capture, checklists, pins, labels, seven colours, search, grid/list, Archive and recoverable Trash, based on the original ZNotes workflows.
- Local JSON imports preserve existing notes with new identifiers. Explicit JSON export is plaintext and includes active, archived and trashed notes.
- Automatic dual-key notebook encryption follows the original ZMail construction: independent keys and nested authenticated AES-256-GCM. Both keys are separately protected by the same OS account; this is not two-factor custody. Existing notebooks are preserved during migration. Exact migration and recovery evidence is recorded separately.

## Existing runtime and release boundaries

OpenZero Gemma4 E2B remains the recommended lightweight local model for direct editions. Qwen3 1.7B and the Fusion model remain excluded. The Store edition does not download models; it uses the user's existing server or optional OpenAI/Groq keys. No company-hosted inference or claimed free-token allowance is included.

ZSEC remains the pinned native selected-folder scanner. The separate ZSEC Antivirus product's background protection update is released independently. Browser Pilot retains its isolated tab and approval controls.

This release restores identified workflows from reviewed public backup source; it is not a claim that every historical PHP feature or all AGI capabilities have been reproduced. Private accounts, database snapshots, provider keys, DNA and retired hosted integrations are excluded. Source edits, tests, packages, Microsoft certification, publication and the installed app are recorded as separate states.
