# ZERO ONE 0.6.0

## One connected OpenZero experience

- The OpenZero workspace now opens the full configured OpenZero panel inside ZERO ONE.
- The quick Assistant, full OpenZero workspace, and Brave Tab Pilot are clearly explained as connected surfaces with different jobs.
- Secure loopback tunnels are correctly treated as server connections rather than mistaken for the lightweight local assistant.
- OpenZero workspace and API settings remain available while the fast local assistant is selected.
- Tab Pilot setup guidance now points users to the automatic local pairing flow.

## Local assistant

- Qwen 3 1.7B remains the fast first-run default for ordinary Windows PCs.
- Larger branded OpenZero models are optional quality modes because they require substantially more disk, RAM, and response time.

## Reliability

- Added regression coverage for the OpenZero workspace address and the three-surface role map.
- Preserved secure operating-system credential storage and existing OpenZero desktop-token pairing.
