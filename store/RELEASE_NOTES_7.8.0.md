# ZERO ONE 7.8

- Adds Assistant actions for checking the currently visible, signed-in ZMail inbox.
- Adds one-click access to the authenticated ZMail composer.
- Keeps mailbox inspection local to the visible workspace and never bypasses login.
- Requires the human to review recipients, subject, body and press Send in ZMail.
- Retains one-click OpenZero Gemma setup, persistent workspaces and the consent-first Tab Pilot connection.

ZERO ONE does not silently send messages or read hidden mailbox data. This boundary prevents an AI mistake from becoming an unintended external communication.
