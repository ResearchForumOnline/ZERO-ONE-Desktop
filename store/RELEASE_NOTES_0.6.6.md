# ZERO ONE 0.6.6

- Adds one-click local OpenZero discovery and credential setup.
- Selects `openzerogemma:latest` automatically when the connected OpenZero runtime reports it.
- Makes the Chrome/Brave Tab Pilot install step prominent without weakening browser consent or store security.
- Keeps the fast Qwen 1.7B model for the everyday local Assistant while reserving OpenZero Gemma for higher-quality browser planning.
- Keeps remote OpenZero server addresses and tokens available as an Advanced option.

Browser stores do not allow desktop apps to silently install extensions. ZERO ONE opens the official listing, while the extension completes local pairing automatically after installation.
