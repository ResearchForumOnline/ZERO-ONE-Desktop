No elevation, drivers, publisher-hosted login or company database. Microsoft Store manages updates. No developer credentials are supplied or required for local notes, offline research or on-demand scans.

ZNotes test: finish welcome; open ZNotes; New note must create a saved record immediately. Enter synthetic title/text, switch to ZeroThink and return; the draft should remain. Test checklist, pin, label, colour, Archive and Trash/restore. Inspect Notebook encryption status: new notebooks use version 2, two independent keys and two authenticated AES-256-GCM layers, with separate keys protected by the same OS account. This is not two-factor custody. Existing version-1 notebooks remain unchanged until the first successful save preserves their exact encrypted backup and commits version 2. JSON import accepts original ZNotes exports without replacing existing notes; native JSON export explicitly warns that it is readable plaintext. Secure OS storage is required; no plaintext fallback.

ZeroThink Studio test: Chat, Research and Agent are native app modules, not a hosted ZeroThink webpage. Chat uses the chosen model and reports missing setup. New chat, rename, pin and saved conversation history persist in an OS-encrypted Studio store. Persona and explicitly entered memory are encrypted locally and included in selected-model context; the latest five remembered statements are used. Add selected TXT/Markdown/CSV/JSON files or ZNotes to the encrypted source library. Select Research with model mode disabled to run an offline evidence map, inspect source excerpts and export a report without API access. Model depth supports bounded draft/critique/final. No scientific verification or AGI claim.

Optional AI: configure an existing OpenZero server or your own OpenAI/Groq key. This Store edition hides and rejects model installation. No automatic cloud fallback or free-token allowance. Optional Serper key enables manual labelled snippet search; opt-in Auto web asks the chosen model whether a public search query is needed. It returns up to three snippets, not full-page reads. Remote providers receive chosen content under their terms. Keys use OS secure storage and are excluded from renderer settings and diagnostics.

Native Agent: choose a synthetic project folder, request file inspection or a small change. Reads/searches remain in selected project and skip common secrets and links/junctions. Each write/command pauses for its exact preview; approval is bound to a unique action ID. Decline, Stop or Escape prevents future execution. Commands run with ordinary OS permissions, not a filesystem sandbox; they have time/output limits. Inspect captured tool results and unfinished state after errors or step limits. No unattended approvals or weight rewriting.

Browser Pilot remains separate, isolated and approval-controlled. ZSEC 0.1.2 is an explicit selected-folder on-demand scanner, not real-time antivirus. Clear desktop data retains ZNotes and encrypted Studio; remove records in their workspaces. Migration backups and readable exports need separate retention management.
