# ZERO ONE Desktop 8.4.0 reviewer notes

Product 9PMPR7PTW025, AppX 8.4.0.0 x64, identity talktoai.ZEROONEDesktop. Package digest is recorded after build in the release receipt.

## Account-free local review

No publisher account, payment or API key is required. Notes, offline research, local quantum and requested scans work without AI weights. **Continue without a model** starts no download.

1. Choose **Set up my CPU AI** or open **OpenZero**, then review/accept displayed model terms. The CPU engine is bundled. Weights download from the pinned publisher revision and are SHA-256 verified: 3,416,119,872 bytes (about 3.42 GB). At least 8 GB RAM and enough disk space are required. No GPU or separate Ollama installation is needed for managed Store/direct mode.
2. Inspect download progress; cancel and retry. Verification/loading errors show retry controls. Once ready, ask a short Assistant/ZeroThink question. Observe acknowledgement, named progress, elapsed time and Stop/Escape cancellation. Stop cannot reverse completed changes.
3. The default OpenZero tile is native setup, with Chat/Research/Agent/Pilot links. Server embedding occurs only in explicit Server mode. Advanced existing Ollama is direct-only. Store app updates stay Microsoft-managed.
4. Create/edit a ZNote, wait for autosave, switch and reopen. Check pins/checklist/labels/archive/trash/restore. Two encryption keys are separately OS-wrapped, not independently held two-factor credentials. Readable JSON export includes archived/trashed notes.
5. Import a small text/PDF source, select it, open Research, disable **Use selected model**, enter a question and run offline evidence mapping. PDF limits: ten MiB/100 pages/one MiB extracted text. Library: 32 documents/two MiB/eight selected sources. Image-only scans require external OCR.
6. Open **Saved research projects**, name/save current work, alter question/process/depth/options, wait for autosave and reopen. Selected source snapshots and latest completed report persist. Cancelled/interrupted work reopens for review and never automatically restarts. Portable JSON contains readable selected evidence/report; keys/device configuration are excluded. Import is bounded to four MiB, creates a fresh project ID and launches no actions.
7. Workbench provides thirteen built-ins and 32 encrypted custom templates. Preview plan/Continue to Research prepares a question; unsaved form fields are not project autosave. Explicit PDF/Markdown/JSON exports do not publish or scientifically verify reports.
8. Local quantum simulation needs no key/network/hardware. ZSEC starts only after a folder selection/request. No automatic quarantine, real-time protection or complete malware prevention is claimed.

## Optional providers and tools

Use the reviewer's own Vault key/model. Chat choices: Groq, OpenAI, Gemini, Anthropic, xAI, NVIDIA NIM, Featherless and compatible server. Serper/IonQ/IBM profiles are separate. Selected chat profiles supply Assistant/Research/Agent/Pilot. There is no publisher key, guaranteed quota or automatic failover. Local prompts remain in authenticated loopback inference; enabled remote services receive selected inputs under provider terms.

Agent requires a project and write/command approvals. Approved commands have ordinary OS permissions, not container isolation. Its 2,048-token planning budget is no longer clamped to quick chat, but context/step/resource limits remain and runs may stop unfinished.

Browser Pilot uses the shared adapter without mandatory server pairing. Explicit isolated-tab grant, structural secret/payment/file/CAPTCHA blocking, cross-site/consequential approval and Stop/12-step limits remain. Snapshots omit form values but may contain private visible text. This is not unrestricted/infallible desktop control.

## Performance, quantum and retention

One real CPU-only i7-2600/3.40 GHz/32 GB check generated 86 tokens at 6.23 tokens/second, with 19.3-second loading and a 28.2-second request. This is a short sample, not a broad speed guarantee or packaged Store acceptance.

IonQ simulator submission needs confirmation. Hardware needs a fresh exact-job estimate and explicit possible-cost approval; review ceilings cannot cap provider charges and remote jobs may outlive Stop. IBM is read-only backend/status discovery, not hardware/Qiskit. No grant credentials/restricted results are bundled.

OS-backed encryption is required; Linux basic_text is refused. Exports retain readable selected content. Clear desktop data preserves credential/settings recovery bytes and retained notes/Studio/templates/projects/model data; it is not universal erasure. Verify reset behavior in the final package.

Privacy: https://researchforumonline.github.io/OpenZero/zero-one-privacy.html. The 8.3 disclosure deployment was previously verified; current 8.4 publication is checked separately. App source is Apache-2.0; engine/weights retain upstream terms. No hosted mail/calls/DNA/admin database, AGI, unrestricted control or weight rewriting is claimed.

Verification: 69 UI and 247 backend tests, TypeScript/build and pinned runtime/ZSEC hashes passed for 8.4.0. Native Electron backend smoke passed with encrypted notes and saved research projects. Packaging and public delivery are pending receipt verification; prior 8.3 tests are historical. Certification and installed Store delivery are separate.
