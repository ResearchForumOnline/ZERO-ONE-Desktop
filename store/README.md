# ZERO ONE Store submission pack

Working-tree product version: `8.2.0`.

Updated 1 October 2026. Working-tree version **8.2.0** is a candidate. The preceding 8.1 update's **Submission 4 is available in Microsoft Store**, as observed in Partner Center on this date. Candidate packaging, upload, certification, public availability and installed version require their own receipts.

This candidate adds the 64-profile, 11-integration private Vault; eight selectable chat providers; native IonQ and read-only IBM Quantum workflows; ten built-in/32 saved custom research templates; Paper Creator/scenario forms; and local PDF imports/readable PDF exports. ZNotes and saved ZeroThink Studio storage remain intact. Clear desktop data preserves those stores and templates, and leaves local encrypted credential/settings recovery copies before resetting current credentials/settings.

Use [8.2 reviewer notes](REVIEWER_NOTES_8.2.0.md), [privacy worksheet](PRIVACY_SUMMARY.md), [full privacy disclosure](../docs/PRIVACY.md), [readiness gate](../docs/STORE_READINESS.md) and [source parity audit](../docs/ZEROTHINK_PARITY_8.2.0.md). The 8.1 release notes and receipt document the preceding version, not the 8.2 outcome.

The Store edition does not download/install local AI models or install direct GitHub updates. Offline research, encrypted notes and selected-folder ZSEC scanning work without an API account. Optional model features use the user's server or chosen cloud provider. API quotas and quantum costs depend on that user's account; no free-token or spending-cap promise is made.
