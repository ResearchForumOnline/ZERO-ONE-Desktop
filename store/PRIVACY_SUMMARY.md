# ZERO ONE Desktop 8.2.0 Store privacy worksheet

Updated 1 October 2026. This worksheet covers the 8.2 source candidate. The preceding 8.1 update's Submission 4 was available in Microsoft Store on this date; the 8.2 packaging/submission/publication state requires its own evidence. Public policy: https://researchforumonline.github.io/OpenZero/zero-one-privacy.html.

| Data or capability | Behavior and required disclosure |
| --- | --- |
| ZNotes | Local dual-key AES-256-GCM notebook, separately OS-wrapped keys under the same account, autosave and organisation. Same-account custody is not independent two-factor protection. Legacy encrypted migration backup persists. Explicit JSON exports are readable and include archived/trashed notes. |
| Studio | Encrypted saved chats, source library, persona and explicit remembered facts. Selected model receives question, bounded conversation/excerpts, persona and latest five facts. Removing sources does not remove excerpts already saved elsewhere. |
| Private Vault | Up to 64 named profiles across 11 integrations; eight chat providers plus Serper, IonQ and IBM. OS-encrypted keys remain main-process only. Renderer gets profile metadata/key-presence flags. Origins/profile names may identify private servers. Linux basic_text is refused. No publisher keys, guaranteed free quota or automatic quota failover. |
| Research Workbench | Ten built-ins and 32 encrypted custom templates. Unsaved paper/scenario fields remain in form memory. Preview is local; sending the prepared Research question with a model transmits supplied notes/selected excerpts. No whole-project autosave or invented results/citations/probabilities. |
| Source imports | Selected text or PDFs copied locally into encrypted Studio. Text source limit one MiB, library two MiB/32 documents, eight selected per run. PDF input ten MiB/100 pages/one MiB extracted text, locally parsed without uploading originals. Image-only scans need external OCR. |
| Research exports | Markdown, JSON and PDF files are readable and unencrypted at a user-selected location; may contain private excerpts and generated drafts. Export does not publish or scientifically verify content. |
| Serper | Optional manual query or opt-in model-generated Auto web query sent to Serper with its service key. Up to three labelled snippets, not full pages. Generated queries may reflect private details in the question; no guarantee that instructions prevent this. |
| IonQ | User-key requests exchange backend/job/estimate/cost/result data; confirmed submission sends circuit, backend, shots, name/settings. Cloud simulator confirmation required. Hardware requires exact matching estimate and explicit possible-cost acknowledgement. Review ceiling cannot cap actual provider charges. Remote jobs may continue after Stop/desktop exit. |
| Local quantum | Bounded ideal classical statevector simulation and reproducible pseudorandom counts; no cloud request/key needed. No hardware, quantum advantage or model-weight improvement claim. |
| IBM | User API key sent to IBM IAM; returned bearer and entered instance CRN used for read-only Quantum backend/status queries in selected region. CRN/region/result stay in current form memory unless explicitly copied/exported. No IBM job submission or instance creation. |
| Quantum reports | Key/token values omitted from reports. Explicit Add to Library stores the report in encrypted Studio; a subsequent model run can send selected excerpts. No automatic transfer of quantum reports to a model. |
| Runtime/preferences | User-configured OpenZero address, selected model/mode and layout stored locally. Launch/30-second/manual/diagnostic probes contact the configured endpoint; remote destination receives network metadata. |
| Embedded sessions | OpenZero and Browser Pilot use separate persistent partitions. Cookies/cache/site storage remain until cleared; visited sites/runtime have their own practices. Camera/microphone denied. |
| Browser Pilot | Explicitly granted bounded tab task; compact visible text/title/labels/redacted URL, viewport and short prior results sent to configured OpenZero planner. Form values omitted, but visible text may contain private data. Structural password/payment/secret/file/CAPTCHA blocking, cross-site/consequential pauses, Stop/revoke and 12-step limit are not infallible/unrestricted control. |
| Native Agent | Selected project files/task/tool results go to chosen model. Writes/commands require approval. Approved commands use normal OS permissions; project working directory is not a sandbox. Stop cannot reverse completed changes or remote effects. |
| ZSEC | User-requested selected-folder scan, local reports may hold paths/hashes/errors. No sample upload, automatic background scan, deletion/quarantine or real-time protection claim. |
| Diagnostics | User-selected JSON with app/system statistics, runtime origin, probe and preference/key-presence flags. No note/chat/page contents or keys. User controls sharing/retention. |
| Clear desktop data | Confirmed reset preserves original settings/Vault bytes as local `.recovery-UUID` files, then removes current settings/Vault, saved logins, browser/runtime partitions and Store-local ZSEC state. Retains ZNotes/keys/legacy backup, Studio and templates. Recovery copies, exports/diagnostics and remote data remain. Not universal purge. |
| Uninstall | Direct NSIS preserves app data; Store-signed uninstall behavior requires Windows verification. No blanket secure-erasure promise. |

Publisher: QUANTUMENCRYPTION1 LTD. Product: ZERO ONE Desktop, Store ID **9PMPR7PTW025**, candidate **8.2.0.0**. Privacy notice hosting is separate from runtime/inference; no company website login/database is required for local features.

Do not answer “no data leaves the device” for remote model, search, quantum or Browser Pilot workflows. Local notes are not automatically sent; selected sources/notes and profile facts can enter a chosen model request. Provider accounts, quotas, billing and retention remain user/provider dependent. The app does not import owner grant credentials or restricted research artifacts.
