## Description

ZERO ONE brings private ZNotes, native ZeroThink research, OpenZero CPU AI, a project Agent, Browser Pilot and on-demand ZSEC scans into one desktop app. Local features need no company-hosted login, website account or database.

Start with **Set up my CPU AI**. ZERO ONE includes the CPU engine, downloads the published OpenZero Gemma4 E2B Agentic Q4_K_M model, verifies its pinned hash and configures local inference. No GPU, API key or separate Ollama installation is required. The one-time download is about 3.42 GB; allow at least 8 GB RAM and enough free disk space. Review model terms before downloading. Cancellation, retry, verification, loading and memory-release controls show actual work. Skip model setup to use notes, offline research and scanning immediately.

Chat with Zero, retain conversations and explicit memory, import selected text/PDF evidence, and run research drafts with source ledgers and review passes. Save named encrypted research projects containing their question, process, depth, options, selected evidence and latest report. Reopen/import projects without automatically launching AI or computer actions. Export readable project JSON or Markdown/JSON/PDF reports when you choose.

The private API Vault supports 64 encrypted profiles. Choose Groq, OpenAI, Gemini, Anthropic, xAI, NVIDIA NIM, Featherless or your compatible server. The selected chat profile supplies Assistant, ZeroThink, Agent and Browser Pilot. Serper, IonQ and IBM are separate service integrations. Bring your own keys; model access, quotas, charges and retention depend on providers. No fixed free-token allowance or automatic quota failover is promised.

The project Agent inspects your selected project, proposes edits and requests approval before writes/commands. Browser Pilot operates one explicitly granted isolated tab, blocks identified secret/payment/file/CAPTCHA actions, pauses for consequential actions and provides Stop plus a step limit. Local AI may respond slowly on older CPUs. These controls do not provide unrestricted or infallible desktop automation.

ZNotes uses dual-key authenticated encryption under OS custody. Saved Studio content, projects, templates and Vault credentials also use OS encryption; Linux requires a secure keyring. Exports are readable and can contain private selected content. Enabled remote AI/search/quantum features transmit selected inputs to configured providers.

Quantum provides bounded ideal classical simulation and optional user-owned IonQ workflows. Hardware requires an estimate and explicit cost approval; estimates do not cap billing. IBM supports backend/status discovery only. ZSEC provides requested selected-folder scans, not certified antivirus or real-time prevention.
