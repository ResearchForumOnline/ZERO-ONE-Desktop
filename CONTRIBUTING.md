# Contributing

Thank you for improving ZERO ONE.

1. Fork the repository and create a focused branch.
2. Run `npm ci` and `npm run check`.
3. Keep remote origins, IPC methods, permissions, and executable arguments deny-by-default.
4. Add tests for security-boundary changes.
5. Do not submit credentials, private datasets, unpublished ZMath research, malware samples, or signing material.

Use GitHub Issues for reproducible bugs and feature proposals. Report vulnerabilities privately through GitHub Security Advisories.
